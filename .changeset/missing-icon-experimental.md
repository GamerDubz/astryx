[experimental] Adds `MissingIcon_experimental` to `@astryxdesign/core/Icon`: a plain dashed-square placeholder for an icon no icon set has. It draws in the current text color, takes its size from CSS or `Icon` like any icon component, and is decorative unless it has an accessible name. Copied templates use it for icons the project's icon sets lack. It may change or be removed in a patch release.
